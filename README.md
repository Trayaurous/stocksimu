# 纸上交易所 · Paper Market

一个中文、纯前端的股票模拟教学游戏。当前是最初测试版，仅有15 家虚构公司、随机行情与公司事件，不接入任何真实股票、指数、账户或交易服务。

## 运行

需要 Node.js 22.18+（推荐 Node.js 24）。

```sh
npm ci
npm run dev
```

打开终端显示的地址，通常为 http://127.0.0.1:5173/ 。

```sh
npm test          # 核心交易 / 行情 / 存档验证
npm run build    # TypeScript 检查和生产构建
npm run preview  # 本地预览 dist/ 中的生产版本
```

必须通过 HTTP(S) 服务打开，不能双击 `index.html` 使用 `file://` 协议。Web Worker、IndexedDB 与 Web Locks 在现代浏览器中运行；生产环境使用 HTTPS，开发环境使用 localhost 或 127.0.0.1。

## 第一版内容

- 初始 10 万虚拟资金，15 家虚构公司；稳定、成长、高波动三种初始参数各 5 家，类型不公开。
- 市场共同波动、不同个股参数、趋势和虚构经营事件。事件可改变行情类型；随机序列不受玩家下单方向影响。
- 1 分钟 / 5 分钟 / 日 K、分时线、成交量、成交标记、股票搜索、排序和自选。
- 市价买入、卖出、做空和平空；1–3 倍开仓杠杆；整数股交易；同一股票不同时持有多空。
- 分开核算现金、多头市值、融资借款、做空保证金、受限卖出所得和空头回补义务。
- 保证金强平、极端跳空后资不抵债、本轮复盘、归档并重新开始。
- 独立交易实验室：价格与盈亏、做空、杠杆对照、保证金、跳空、交易成本。预设行情可重播，与主游戏共用结算引擎。
- 仅首次买入、做空、使用杠杆、持仓价格首次变化有可关闭的说明；主游戏不提供买卖指令或评价输赢是否“正确”。
- IndexedDB 自动存档、localStorage 恢复副本、JSON 导入导出、单标签页互斥。
- 青绿涨 / 珊瑚跌与红涨 / 绿跌两套配色，响应式桌面及移动布局。

## 时间规则

新一轮从现实当前时刻开始，固定 UTC+8。周一至周五 09:30–11:30、13:00–15:00 开市，不接入现实节假日。

顶栏默认只显示数字形式的游戏时间，点击可展开完整日期、开休市状态、倍率和时间规则；主交易区从账户卡片开始。

前台倍率为 1×、10×、60×、600×。切换到后台或进入实验室时回到 1×。休市时可以跳到下一次开市，期间费用仍会结算。**退出后不保留加速倍率**：下次进入时，在已保存的游戏时间上加上现实离开时长，不重新对齐现实日期。

行情以分钟报价推进，休市时跳过无报价的时间段，但按自然时间收取资金成本。离线与在线使用同一模拟引擎，依次处理途中报价、事件及强平，不只计算最终价格。行情计算运行在 Web Worker 中。

初次创建会生成约 35 天的历史行情，以便观察；初始价格参数、随机种子和模拟状态使同一存档的后续行情可复现。

## 简化交易规则

以下是游戏规则，不代表任何现实交易所：

| 项目       | 规则                                               |
| ---------- | -------------------------------------------------- |
| 初始资金   | ¥100,000                                           |
| 市价滑点   | 每次成交固定 0.03%，方向对交易者不利               |
| 手续费     | 双边各 0.1%，每笔最低 ¥1                           |
| 融资费用   | 借款本金 × 年率 10%，按 365 天自然时间计费         |
| 借券费用   | 空头当前回补市值 × 年率 5%，按 365 天自然时间计费  |
| 开仓限制   | 成交后多空总敞口 ≤ 净资产的 3 倍，计入费用和滑点   |
| 维持保证金 | 净资产 ÷ 多空总敞口 ≤ 25% 时，在可成交报价全部强平 |
| 本轮结束   | 净资产 ≤ 0，禁止继续开仓，允许查看复盘和重新开始   |

净资产 = 现金 + 多头市值 − 融资本金 + 做空保证金 + 受限卖出所得 − 空头回补市值。

做空卖出所得被锁定，不会增加可用现金。部分平仓按比例归还融资或释放做空保证金。账户总盈亏包含全部费用；单笔平仓盈亏只扣除该次平仓手续费，未分摊开仓费或时间成本。

分钟 K 线的影线用于表示模拟区间，**实际撮合和强平只使用分钟报价**。当市场休市，风险在下一次可成交报价处理；跳空可能让强平后的净资产为负。首版不包含限价单、止损单、分红、拆股、真实财报、税制或现实节假日。

## 存档与数据保留

- 存档版本：1。每次交易及重要操作后保存，日常时钟约每 5 秒保存一次；离开页面时尝试保存最新快照。
- IndexedDB 数据库：`paper-market`，对象仓库：`saves`；localStorage 恢复副本：`paper-market-save-v1`。
- 保留每家公司最近 480 根分钟 K 线与 120 根日 K；最近 1,000 笔成交、80 条市场公告及 50 轮结算摘要。
- 早期净资产采样会逐步稀疏化，但最大回撤在实际报价时持续更新。
- 关闭页面的瞬间若尚未收到 Worker 响应，会从最后一份成功快照按 1× 恢复；正常自动保存的误差窗口约 5 秒，不承诺操作系统强制结束进程时的零丢失。
- 导入先验证版本、结构和数值，再替换内存与本地存档；离线时间也会补算。
- 存档按浏览器及网站 origin 隔离。开发端口和生产预览端口各有独立存档；部署后可通过导出 / 导入迁移。
- 重新开始保留结算摘要与首次说明进度；教程完成进度和配色作为浏览器偏好单独保存。完整旧轮次明细请先导出。
- 没有云同步和反作弊；清理网站数据会丢失本地存档。页面加载后模拟不依赖网络，但首版不提供 Service Worker 的离线页面安装 / 重开保证。

## 部署到 GitHub Pages

项目使用相对资源路径（`base: './'`）和 Hash 导航，可部署到 `https://用户名.github.io/仓库名/`，无需修改仓库名前缀。

1. 把本目录源码和 `package-lock.json` 上传到 GitHub 仓库的 `main` 分支，不上传 `node_modules/`。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送到 `main` 或手动运行 **Deploy to GitHub Pages** 工作流。
4. 工作流执行 `npm ci`、`npm test`、`npm run build`，随后发布 `dist/`。

如果使用其他分支名，修改 `.github/workflows/deploy.yml` 的分支配置。也可以把 `dist/` 内容发布到任何支持静态文件的 HTTPS 服务器，无需后端、环境变量、数据库服务或 API 密钥。

## 文件结构

```text
src/
  simulation/    交易日历、确定性随机行情、类型、公司数据、Worker
  trading/       市价成交、借款 / 做空记账、保证金与强平
  storage/       IndexedDB / localStorage 持久化和导入验证
  education/     六个预设教程与独立实验界面
  components/    K 线、下单面板、弹窗
  useSimulation.ts  Worker 协调、时钟、单标签页锁、自动保存
  App.tsx        主交易台、复盘、公司档案与设置
  styles.css     响应式界面与两套行情配色
tests/
  engine.test.ts  交易与模拟规则回归测试
.github/workflows/deploy.yml  GitHub Pages 自动部署
```

## 验证范围

自动测试覆盖开休市边界、种子复现、K 线有效性、多头与空头结算、部分平仓、非法订单无副作用、跨持仓杠杆限制、强平不可逆、跳空破产、周末计息、在线分段与离线批量一致，以及损坏存档拒绝。

浏览器检查覆盖生产构建启动、开市跳转、买入 / 杠杆 / 做空 / 平仓、首次说明、刷新持仓恢复、六个独立教程、存档导出 / 导入、轮次归档、多标签页互斥，以及桌面和移动端布局。生产发布之前仍可按自己的设备和使用习惯进行试玩，调整模拟波动与费用等游戏参数。
